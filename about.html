About

The workshop

Ancient Access is a small workshop for SillyTavern roleplay — character cards, a main preset, and supporting tools, all built as one interlocking system.

Everything here follows the same philosophy. Each character is hyperfocused on delivering a single, specific experience: the blurb states it, the systems inside the card enforce it. Settings are researched properly — historical texture, folklore traced to its sources, psychology treated as machinery rather than decoration. The preset runs first person because interiority is the entire point. These are deliberate craft choices, and the catalogue stays small because each release is engineered and tested until it holds.

Everything is free. You are welcome to customise and repurpose parts of the prompts and character cards, however if you end up uploading the full card on a platform like Chub or JanitorAI, please include a link to this website.

There are no commissions and no donations. If you have an idea for a character or a feature, you're welcome to send it through the contact page — anything genuinely interesting may end up on the workbench.

New here? The Setup Guide covers installation and how the pieces fit together. Otherwise: download Prompts and Characters by using the navigation menu. Go play.

Setup guide

Everything below assumes SillyTavern. Other frontends may work with modification, and you're on your own there.

1. Install the preset

Download the preset JSON from Prompts. In SillyTavern, open the AI Response Configuration panel (the sliders icon, top left), find the preset dropdown, and use the import button beside it to load the file. Select it as your active preset.

Skim the prompt list once after importing. The preset is modular — the core blocks stay on, and optional modules ([Plot Driver, NPC Dynamic Mode, Multi-char POV, Adult content]) can be toggled per chat depending on what your scene needs.

2. Import a character

Download the character JSON from Characters. In the Character Management panel (top right), select Import Character from File and choose the file. That's all it takes.

3. Read the Author's Note / creator notes — every time

This is the step people skip, and it's usually why a character misbehaves. Each card states its own requirements:

  • Some characters run on the main preset as-is.
  • Some ship with a customised version of the preset baked into their prompt override. For these, the notes will tell you to disable the main preset's [system prompt / overlapping modules] so the two don't conflict.
  • Character-specific toggles, POV notes, and content flags live there too.

The card's blurb tells you what experience you're signing up for. The notes tell you how to get it. Both are short — read both.

4. Set up the summariser (optional, recommended for long chats)

The summariser is distributed as plain text — copy it from PDF, which you can download from Prompts. It's written for SillyTavern's built-in Summarize extension: open Extensions (the blocks icon), find Summarize, set it to use the main API, and paste the prompt into the prompt field, replacing the default.

Since it's plain text, it also transplants into whatever memory extension you prefer — trim and restructure at will.

5. Quick Reply sets (character-specific)

Some characters (Struan, Gundahar) come with a Quick Reply set that adds extra mechanics. Import it via Extensions → Quick Reply → import, then enable the set. The character's notes explain what the buttons do.

If something breaks

Check the Author's Notes first, then confirm the preset imported cleanly and the right modules are toggled. Still stuck? Send a message through Contact with your model/backend and a description of what happened.
